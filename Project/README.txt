JAMAL ASHIK & SUGARAL SHIFANA — NIKAH INVITATION

1. Open the folder in VS Code.
2. Put your fonts inside assets/fonts/ using the filenames listed in assets/fonts/README_FONTS.txt.
3. Put groom.jpg in assets/groom/
4. Put bride.jpg in assets/bride/
5. Put mosque.jpg in assets/mosque/
6. Put gallery images as 01.jpg, 02.jpg, 03.jpg in assets/gallery/
7. Put background.mp3 in assets/music/ (optional).
8. Open index.html with Live Server.

MUSIC AUTOPLAY:
The background music is configured to autoplay automatically. Modern browsers can block audible autoplay until the user interacts with the page; when that happens, the site retries playback on the first click/touch/key press, including the OPEN INVITATION button. The music button remains as an optional manual toggle.
